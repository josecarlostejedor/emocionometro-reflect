# Emociómetro – Reflect + Streamlit

Esta aplicación integra Microsoft Reflect como herramienta de votación emocional 
y Streamlit para publicarla en la web.

## Estructura
- `app.py`: aplicación Streamlit
- `emocionometro.html`: mini-aplicación que gestiona votación + marcador
- `requirements.txt`: dependencias

## Cómo ejecutar localmente
```bash
pip install -r requirements.txt
streamlit run app.py
